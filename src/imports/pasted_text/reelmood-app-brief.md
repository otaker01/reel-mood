Create a complete modern web application called "ReelMood" — an intelligent movie recommendation and discovery platform that helps users find movies based on their current mood, preferences, situation, genres, and viewing habits.

The platform should feel cinematic, premium, modern, and highly visual. It should not look like a traditional movie database. The main focus is helping users answer:

"What should I watch tonight?"

Users should be able to select multiple filters such as:
- Mood
- Genre
- Situation
- Energy level
- Time available
- Release year
- Movie rating
- Popularity
- Streaming platform

Based on their selections, the platform dynamically recommends movies.

==================================================
CORE CONCEPT
==================================================

The experience should feel simple and fun.

Instead of forcing users to search through thousands of movies, guide them through a personalized movie discovery experience.

Example:

"What are you in the mood for?"

User selects:
✓ Watching alone
✓ Feeling lonely
✓ Something emotional
✓ Drama
✓ Slow-paced
✓ Under 2 hours

The platform recommends movies that match this combination.

Another example:

✓ Watching with friends
✓ High energy
✓ Funny
✓ Action
✓ Popular
✓ Under 2 hours

The platform recommends a completely different set of movies.

Users should be able to select multiple categories at the same time.

==================================================
DESIGN STYLE
==================================================

Create a premium cinematic interface.

Visual direction:
- Dark mode by default
- Deep black / dark navy background
- Clean modern interface
- Large movie posters
- Cinematic imagery
- Subtle gradients
- Minimal UI
- Rounded cards
- Soft shadows
- Modern typography
- Spacious layouts
- High-quality visual hierarchy

The platform should feel like a combination of:
Netflix + Letterboxd + Spotify recommendations

But with a more modern and unique product design.

Avoid:
- Outdated movie database layouts
- Too much text
- Small cluttered UI
- Generic dashboard designs
- Excessive borders

Use movie artwork as the main visual element.
